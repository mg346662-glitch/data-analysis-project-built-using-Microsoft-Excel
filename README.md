# 📊 Advanced Excel Business Intelligence & Analytics Suite

An end-to-end business intelligence and analytics project built **entirely using Microsoft Excel**, designed to transform raw transactional data into actionable insights through robust data modeling and interactive reporting.

---

## 🚀 Project Overview
This project simulates a comprehensive retail and order analytics system. It demonstrates how advanced built-in Excel features can be leveraged to build a complete BI solution—matching the capabilities of dedicated visualization tools—complete with dynamic filtering, data modeling, and multi-perspective executive dashboards.

---

## 🛠️ Tools & Techniques Used
* **Power Query (ETL):** Extracted, transformed, and cleaned raw datasets, establishing automated data preparation pipelines.
* **Power Pivot & Data Modeling:** Built relational star-schema data models, created calculated columns, and handled complex data relationships across multiple tables.
* **Pivot Tables & Advanced Formulas:** Used for deep-dive exploratory data analysis, aggregation, and segmentation.
* **Interactive Dashboards:** Designed four distinct, user-friendly, and visually polished interactive dashboards equipped with slicers.
